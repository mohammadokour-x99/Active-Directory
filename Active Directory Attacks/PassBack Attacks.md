# PassBack Attacks

<?xml version="1.0" encoding="UTF-8"?>
<node><rich_text>A passback attack a security exploit where an attacker reconfigures a network device—like a multifunction printer (MFP) or server—to point its integrated service settings (such as LDAP or SMTP) to a rogue, attacker-controlled server to capture credentials in plaintext.

</rich_text></node>
